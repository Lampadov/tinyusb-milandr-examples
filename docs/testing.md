# Проверка USB на плате

Соберите и прошейте нужную цель из [проекта Keil](../USB_EXAMPLES.uvprojx). Команды ниже запускаются из корня репозитория. Подставьте COM-порт и букву тома отладочной платы.

## Повторная энумерация в Windows

Запустите терминал от имени администратора. Скрипт циклически переподключает порт USB-хаба и проверяет состояние устройства после каждого цикла.

```powershell
python tools/enum_test.py msc-webusb 250 0.3
```

Для первого аргумента доступны значения `cdc-only`, `hid-mouse`, `hid-keyboard`, `msc-only`, `webusb-only`, `msc-hid` или `msc-webusb`. Далее идут число циклов и пауза в секундах.

## Нагрузка на CDC

Для `CDC_ONLY` установите `pyserial`. Закройте другие программы, использующие этот COM-порт. Режим `all` запускает тесты потоковой передачи, эха и повторного открытия порта. Длительность задаётся для каждого режима.

```powershell
python -m pip install pyserial
python tools/cdc_stress.py COM5 all --minutes 5
```

## Нагрузка на MSC

Режим `raw` читает том случайными блоками. Режим `files` создаёт, перезаписывает и удаляет тестовые файлы на выбранном томе, проверяя их содержимое. Используйте `files` на томе платы с `MSC_ONLY` или `MSC_HID`. Для `MSC_WEBUSB` используйте `raw`, поскольку том доступен только для чтения.

```powershell
python tools/msc_stress.py raw '\\.\E:' --minutes 5
python tools/msc_stress.py files 'E:\' --minutes 5
```

## WebUSB и HID

Для `HID_MOUSE` и `HID_KEYBOARD` проверьте движение курсора и ввод в пустом текстовом документе. В `MSC_HID` сохраните тестовый текст в `TEXT.TXT`, установите фокус в редактор и нажмите **SELECT**.

Для одного из вариантов WebUSB откройте страницу в Chrome или Edge, подключите плату и проверьте управление светодиодами, отображение нажатий и обновление графика АЦП. [WEBUSB_ONLY](../examples/webusb-only/README.md) · [MSC_WEBUSB](../examples/msc-webusb/README.md).

После редактирования файлов страницы `MSC_WEBUSB` обновите образ FAT12 и пересоберите прошивку.

```console
python tools/make_disk.py
```
